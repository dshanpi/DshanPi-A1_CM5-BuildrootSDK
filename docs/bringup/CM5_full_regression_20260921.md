三摄映射按媒体拓扑：m00=I2C2/vir0，m01=I2C3/vir1，m02=I2C5/vir3。
本机 video-camera0 别名实际指向 m02，不能据别名推断物理 CAM0。
AIQ 持续报 `aec_stats_valid=false,meas_type=0x0` 和 `AWB stats invalid`，
应先核对当前 ISP 配置/统计路径，不能继续只靠提高增益掩盖问题。

网络统计窗口含主动隔离网口测试；其丢包比例不能直接当硬件故障率。
物理 Link Down 不能由 IP 地址冲突单独解释。Wi-Fi 测试曾临时关闭省电。
三摄与网络窗口部分重叠，不宣称全部功能同步满10分钟通过。

测试结束恢复原单摄预览、ALSA 状态、Wi-Fi 省电和两网口 up，停止临时蓝牙初始化。
没有修改持久网络配置。现场照片、录音、网络地址及原始日志只留 SDK 本地输出目录，
不随此差分包上传。下一步优先排查 ISP 统计、双网口稳定性和录音。
